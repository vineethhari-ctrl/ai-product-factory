## Please read before sharing

- All four videos were recorded with the **built-in offline engine** (no AI key in the recording environment), and the video says so.
- The example input was a short brief written by the presenter, not the original business requirement.
- The VoltTrust example is **not** the real VoltTrust prototype: the real one has a hash-chained ledger, two-device attestation, a public anchor, a tamper simulator, a resale certificate and per-OEM tenants. The factory's offline output is a generic workbench and does not show these.
- Output quality with Gemini on Vertex AI has not been verified in these videos.
